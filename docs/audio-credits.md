# Battle audio credits

All four distributed battle clips are OGG Vorbis mono and are Creative Commons Zero
(CC0) sounds by Kenney, reused without a license fee. They remain part of the
original Kenney sound packs; no BattleTech intellectual-property audio was used.

| Shipped file | Original Kenney file | Source pack | License |
|---|---|---|---|
| `assets/audio/heavy_impact.ogg` | `explosionCrunch_000.ogg` | [Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds) | CC0 |
| `assets/audio/laser_alert.ogg` | `confirmation_001.ogg` | [Interface Sounds](https://kenney.nl/assets/interface-sounds) | CC0 |
| `assets/audio/step.ogg` | `click_002.ogg` | [Interface Sounds](https://kenney.nl/assets/interface-sounds) | CC0 |
| `assets/audio/ui_click.ogg` | `click_001.ogg` | [Interface Sounds](https://kenney.nl/assets/interface-sounds) | CC0 |

These are short mono files (roughly 4–28 KB). They were retrieved from
the CC0 Kenney-derived asset set of the open-source Brickstorm project
([source credits](https://github.com/manuel-palacio/brickstorm/blob/main/CREDITS.md)).
Distinct event families reuse these clips at different pitch scales; the sound
selection is an aesthetic placeholder for a future, larger CC0 palette.

Audio clips never drive attacks, damage, dice, heat or game progression.
