# Content expansion

Six procedural themes and three original fixed maps; two visual building alternatives and four small doodad kinds, all cosmetic (no movement or LOS changes). The existing tactical map tests cover the new themes. Five advanced training exercises follow the six basic missions, using the same save and practice system. Their practice checks are generic movement/fire checks, not proof of specialist-rule mastery. No new rules. Chaos campaign offers have persistent fictional employer, location and mission-specific hook, with feedback from the previous contract; results carry the title into the after-action report. Map HQ has a deterministic daily dispatch using only public/player information. Narrative is flavor, not a new economy or branching contract system. Existing contracts without story remain readable. Historical campaign source assessment is separate.

Godot CI and Android device validation are required; no APK is requested.
