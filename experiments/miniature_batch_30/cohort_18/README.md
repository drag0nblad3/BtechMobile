# Eighteen additional experimental sculpts

Stacked on #297; no production files edited. Actual CGL plastic photos inspected from Jaded Falconer's catalog; Catapult and Warhammer additionally compared against painted CGL plastic photos from Mech Painters Union. Other 16 need additional views. Catalog variant labels are targets for the sculpt, not validated game unit design mappings. Some catalog variants differ from main; source spec unit IDs are placeholders.

18 independent loft assemblies with a shared humanoid attachment topology where appropriate; Catapult, Adder and Locust have distinct digitigrade layouts. 350 selected components, 126 contour trials, 3030 changed cells relative to structurally repaired controls. 18/18 pass exclusive occupancy, connected part and two-layer-backed parent patch checks. 17/18 improved diagnostic mask scores; Adder retained control. Initial and repaired records preserve decisions, including integrated knee overlays and shifted Hatchetman axe grip. Body/arm/leg masks approximate, only leg poses fitted on most views, arm poses not fully registered; camera RMSE varies considerably. No production comparison, runtime rig testing, exact weapons validation or Godot testing. Not ready to merge.
